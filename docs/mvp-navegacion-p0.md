# P0 — Navegación MVP (Hoy + Mis cursos)

## Qué cambió

- Menú principal: **Hoy**, **Mis cursos**, **Planificaciones**, **Configuración**.
- Administración (usuarios, establecimientos, currículum) solo si el usuario tiene permiso.
- **Hoy**: saludo, clases del día con «Preparar clase», pendientes y próximas clases.
- **Mis cursos**: lista simple; al entrar, hub con nueva planificación, planificaciones del curso y nómina.
- Dashboard API: `TodayClasses`, `PendingItems`, nombres de curso/asignatura/unidad en `UpcomingClassDto`.
